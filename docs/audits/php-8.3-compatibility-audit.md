## 変更GO時のAcceptance Criteria（Issue本文より）

- [ ] 変更前バックアップ/rollback経路 VERIFIED
- [ ] WP/Cocoon/主要プラグインのPHP 8.3互換性に重大懸念なし
- [ ] PHP 8.3へ切替後、トップ＋主要5ページ HTTP 200
- [ ] wp-admin正常
- [ ] PC/mobile主要ページにFatal/崩れなし
- [ ] GA4 `G-E73FEQEWNF` 発火継続
- [ ] Search Console/SEO設定に意図しない変更なし
- [ ] フォーム/主要内部リンク/主要CTA正常
- [ ] 新規PHP Fatal 0

## Stop Conditions（Issue本文より）

- PHP 8.3非互換のテーマ/プラグインを確認
- 切替前バックアップ/rollbackを確認できない
- 本番変更以外に検証手段がなく、影響範囲を絞れない
- 秘密値出力が必要
- 切替後Fatal/管理画面不能/主要ページ異常が発生した場合は即rollback

## 注記

- 本監査段階ではPHP変更、WP/テーマ/プラグイン更新を実施しない。
- 更新が必要な場合は「PHP切替前提更新」として変更順序を別途提示し、Owner GOで停止する。
- P0-Aの変更後ベースライン蓄積を汚さないよう、実PHP切替タイミングは調整する。
